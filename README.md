# bicikle_rent
Крок 1
Іменники
місто, станція (прокату), велосипед, звичайний велосипед, електричний велосипед, номер, клієнт, ім'я, баланс, рахунок, хвилина, кількість хвилин, гривня, вартість, гроші, поїздка, адміністратор, мережа, замовник	
Дієслова
стоять (на станції), бути (звичайним / електричним), мати (ім'я, баланс), взяти (велосипед), покататись, повернути (велосипед), коштувати, списуватися (гроші), бачити (кількість велосипедів), заробити
Крок 2
Велосипед	Клас	має власні дані: номер і тип
Станція	Клас	має власні дані: назву та список велосипедів
Клієнт	Клас	має власні дані: ім'я та баланс
номер	Атрибут Велосипеда	це дані велосипеда
тип (звичайний / електричний)	атрибут Велосипеда	від нього залежить ціна хвилини
ім'я, баланс	атрибути Клієнта	це дані клієнта
хвилини, кількість хвилин	параметр функції	це не властивість об'єкта, а вхідне значення для поїздки
гривня, гроші, вартість	число	результат розрахунку, не клас
поїздка	функції (не клас)	поїздка миттєва й нічого не зберігає: це дії «взяти» та «повернути»
адміністратор	атрибут	це той самий клієнт тільки з більшими можливостями
Крок 3
бути звичайним / електричним	Велосипед	атрибут «тип»
коштувати (за хвилину)	Велосипед	метод, що повертає ціну хвилини залежно від типу
стоять на станції	Станція	список велосипедів + метод «додати велосипед»
бачити, скільки велосипедів	Станція	метод, що повертає кількість (друкує лише звіт)
взяти велосипед (зі станції)	Станція	метод «забрати велосипед», повертає велосипед або None, якщо станція порожня
повернути велосипед (на станцію)	Станція	той самий метод «додати велосипед»
списуватися (гроші)	Клієнт	метод «списати», повертає True / False
мати ім'я, баланс	Клієнт	атрибути
покататись N хвилин	функція поїздки	параметр minutes
порахувати вартість	функція поїздки	хвилини × ціна хвилини
взяти й повернути велосипед як одна дія	функції поїздки	викликають методи Станції та Клієнта
заробити (загальна виручка)	облік виручки	сума всіх списань
